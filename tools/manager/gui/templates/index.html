You can change the four fields below. The dates, the name and the folder are not editable here — “last activity” means the newest acquisition in the project, not the last time someone edited it, so editing a description must not move it. Renaming a project touches its folder and every link inside it, so it is a Data Office job for now.

Create a project

Anyone with access to gjesus3 may create a project — but always through this tool, never by making a folder by hand. That is what keeps the registry, the folder name and the project file consistent with each other.
